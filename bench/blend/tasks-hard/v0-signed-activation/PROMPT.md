# Verify v0 signatures against bank-relative ALT activation

Repair the existing implementation of `solve(input)` in this small offline Node 22 package. Preserve the API; edit the implementation modules, not tests. No packages, network, RPC, filesystem or clock are needed. Several modules contain interacting defects. The intended fix is compact; do not replace the package with a large framework.

Input {message,signatures,tables,slot,recentSlots}. Parse a strict canonical full v0 message; required signatures >=1, fee payer must be writable, no duplicate static keys or lookup-table descriptors, no repeated index within/between writable/readonly of one descriptor, total resolved keys <=256. Programs must be static; instruction account indices must be in range. Reject noncanonical short-u16, truncation or trailing bytes. Each supplied table {key,data} is a full ALT account: state u32 LE=1; deactivationSlot u64 at 4; lastExtendedSlot u64 at 12; startIndex u8 at 20; authority Option tag 0/1 at 21 (payload and padding ignored); 56-byte metadata then <=256 32-byte addresses; startIndex<=count. Slot and recentSlots entries are u64 strings. Require extended<=slot; when equal only prefix startIndex is usable, otherwise all addresses. A table is active if deactivation is u64::MAX, equals slot, or is an earlier slot present in recentSlots. Validate all supplied tables, reject duplicate keys. Resolve ALL writable loads then ALL readonly loads; reject any duplicate resolved key including static/loaded collisions. Verify EXACTLY required signatures, each 64 bytes, against corresponding static signer key with Ed25519 over the EXACT original message bytes. Return {keys,signers,writable}; writable is a bool per resolved key, using header partitions and loaded roles.

All byte strings are canonical lowercase even-length hex. Unsigned token/lamport amounts are canonical decimal strings in [0, 2^64-1]. Indices/epochs are nonnegative safe integers unless a narrower bound is stated. Reject malformed/out-of-range inputs with exactly `{error:"invalid"}`; never mutate input, even on failure. Successful BigInt values are returned as decimal strings by the existing entrypoint. Do not silently coerce numeric strings or repair malformed wire data.

Run `node --test visible.test.ts`. Hidden tests also cover coupled invariants and boundaries; passing the public examples alone is not the contract.
