# Enforce CPI frame conservation and nested account rollback

Repair the existing implementation of `solve(input)` in this small offline Node 22 package. Preserve the API; edit the implementation modules, not tests. No packages, network, RPC, filesystem or clock are needed. Several modules contain interacting defects. The intended fix is compact; do not replace the package with a large framework.

This is a bounded account-runtime journal, not a full Solana interpreter. Input {program,accounts,ops}; accounts are unique {id,owner,writable,lamports,data}, IDs/owners strings, writable bool. Ops: {kind:"set",id,lamports} sets a balance (credits permitted to any writable owner, debits only program-owned writable accounts); {kind:"write",id,data} replaces program-owned writable data; {kind:"read",id} appends ['read',id,lamports,data]; {kind:"fail"}; {kind:"invoke",program,ops,catch}. Every frame must preserve TOTAL lamports independently, with u64 per-account bounds. A failed child restores its accounts and emitted events; catch:true lets parent continue. A successful child commits into parent, but a later parent failure reverts child effects too. Output {committed,accounts,events}; failure of root restores original accounts and empties events. 'set' appends ['set',id,lamports], 'write' appends ['write',id,data]. Reads don't require writability. At most 64 ops/frame, depth <=8. Malformed INITIAL state returns invalid; any malformed operation fails its enclosing frame. Input must remain untouched.

All byte strings are canonical lowercase even-length hex. Unsigned token/lamport amounts are canonical decimal strings in [0, 2^64-1]. Indices/epochs are nonnegative safe integers unless a narrower bound is stated. Reject malformed/out-of-range inputs with exactly `{error:"invalid"}`; never mutate input, even on failure. Successful BigInt values are returned as decimal strings by the existing entrypoint. Do not silently coerce numeric strings or repair malformed wire data.

Run `node --test visible.test.ts`. Hidden tests also cover coupled invariants and boundaries; passing the public examples alone is not the contract.
