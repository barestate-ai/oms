# Compile privilege unions into a canonical v0 message and ALT index space

Repair the existing implementation of `solve(input)` in this small offline Node 22 package. Preserve the API; edit the implementation modules, not tests. No packages, network, RPC, filesystem or clock are needed. Several modules contain interacting defects. The intended fix is compact; do not replace the package with a large framework.

Input {payer,blockhash,instructions,tables}. Keys/blockhash exactly 32 bytes. instructions are {program,accounts:[{key,signer,writable}],data}; flags must be booleans. tables are {key,addresses:[key,...]} with unique table keys, <=256 addresses each. Union roles across all occurrences, payer always writable signer; program IDs always remain static (even when present in tables). First encounter order is payer, then each instruction's account metas, then its program ID. Eligible nonsigner/nonprogram keys use the FIRST supplied table containing them. Static keys retain first encounter order WITHIN these groups: payer, other writable signers, readonly signers, writable nonsigners, readonly nonsigners. Used table descriptors remain in input-table order; selected writable and readonly indices are ascending within each table. Global loaded keys are ALL table writables followed by ALL table readonlys. Emit {message,signerKeys,loadedWritable,loadedReadonly}; message is full canonical version-0 Solana message hex, with short-u16 lengths, header derived from static roles, exact compiled instruction order/data, and only used lookup descriptors. Preserve duplicate instruction account occurrences. Empty instructions permitted; total resolved keys <=256, at most 255 signers, and all lengths short-u16.

All byte strings are canonical lowercase even-length hex. Unsigned token/lamport amounts are canonical decimal strings in [0, 2^64-1]. Indices/epochs are nonnegative safe integers unless a narrower bound is stated. Reject malformed/out-of-range inputs with exactly `{error:"invalid"}`; never mutate input, even on failure. Successful BigInt values are returned as decimal strings by the existing entrypoint. Do not silently coerce numeric strings or repair malformed wire data.

Run `node --test visible.test.ts`. Hidden tests also cover coupled invariants and boundaries; passing the public examples alone is not the contract.
