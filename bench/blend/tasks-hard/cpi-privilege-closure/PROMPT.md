# Audit nested CPI privilege unions and caller-bound signer grants

Repair the existing implementation of `solve(input)` in this small offline Node 22 package. Preserve the API; edit the implementation modules, not tests. No packages, network, RPC, filesystem or clock are needed. Several modules contain interacting defects. The intended fix is compact; do not replace the package with a large framework.

Input {accounts,frame}; accounts are unique {key,signer,writable} capabilities, with 32-byte keys and boolean flags. frame recursively has {program,metas,derived,children}; metas may repeat keys and are unioned by OR in first-appearance order. Every program must be present in its parent's capabilities. Child requested writable requires parent writable. Child requested signer requires parent signer OR a valid derived grant. A derived grant {key,seeds} uses <=15 hex seeds of <=32 bytes and key MUST equal SHA256(concat(seeds)||CALLER program bytes||ASCII("ProgramDerivedAddress")); this is an offline signer-transcript digest fixture, NOT an off-curve PDA implementation. All grants must validate, even unused ones; no grants allowed at root. Grants permit signing only, never writability; ancestor grants don't persist automatically beyond the requested child flags. Frame depth <=8, <=64 frames, <=256 metas/frame, no unknown accounts. Return a preorder array [{program,metas:[{key,signer,writable}]}] of the merged REQUESTED flags, not inherited parent flags. Reject the whole tree on any privilege escalation, invalid proof or malformed node; do not mutate inputs.

All byte strings are canonical lowercase even-length hex. Unsigned token/lamport amounts are canonical decimal strings in [0, 2^64-1]. Indices/epochs are nonnegative safe integers unless a narrower bound is stated. Reject malformed/out-of-range inputs with exactly `{error:"invalid"}`; never mutate input, even on failure. Successful BigInt values are returned as decimal strings by the existing entrypoint. Do not silently coerce numeric strings or repair malformed wire data.

Run `node --test visible.test.ts`. Hidden tests also cover coupled invariants and boundaries; passing the public examples alone is not the contract.
